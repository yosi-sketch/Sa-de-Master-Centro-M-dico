# Saúde Master Centro Médico — Landing Page Oficial
## "Envelhecer bem é viver com autonomia."

Landing page oficial de alta conversão para o **Saúde Master Centro Médico**, clínica de especialidades médicas e cuidado integral em Mateus Leme - MG.

---

## 🌿 Tecnologias Utilizadas
- **Next.js 16 (App Router)**
- **React 19**
- **Tailwind CSS 4**
- **Framer Motion**
- **Lucide React**
- **Sharp** (geração e otimização automatizada de assets médicos e favicons)
